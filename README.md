## What I'm building

### [zug-tracker](https://github.com/rickyfrancis/zug-tracker)

A live map of German long-distance trains, in the spirit of FlightRadar24.
Positions come from GTFS schedules and GTFS-Realtime feeds, and every train
reports whether its position is realtime-backed or schedule-estimated.

`Python` `FastAPI` `PostGIS` `Redis` `Next.js` `MapLibre GL`

### [lingua-layer](https://github.com/rickyfrancis/lingua-layer)

A browser extension adding dual subtitles and word-level translation to Prime
Video. Hovering a word pauses playback — a subtitle is on screen for about two
seconds, so without pausing, reading a translation is a race against the next
line. Translation runs entirely on-device through Chrome's Translator API: no
backend, no account, nothing leaves the machine.

`TypeScript` `Chrome Extension APIs`

### [vashabid](https://github.com/rickyfrancis/vashabid)

A Next.js 16 application built on Payload CMS 3 and PostgreSQL, with a
dev-container setup so the database and toolchain come up identically on any
machine.

`Next.js` `Payload CMS` `PostgreSQL` `Docker`

### [issue-tracker](https://github.com/rickyfrancis/issue-tracker)

Issue tracking with authentication, assignment, filtering and dashboard charts.
— [live demo](https://issue-tracker-one-snowy.vercel.app)

`Next.js` `TypeScript` `Prisma` `NextAuth` `Radix UI`
