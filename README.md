## What I'm building

### [zug-tracker](https://github.com/rickyfrancis/zug-tracker)

A live map of German long-distance trains, similar to FlightRadar24. It reads
GTFS schedules and GTFS-Realtime feeds, and each train shows whether its
position comes from live data or from the timetable.

`Python` `FastAPI` `PostGIS` `Redis` `Next.js` `MapLibre GL`

### [lingua-layer](https://github.com/rickyfrancis/lingua-layer)

A Chrome extension that shows German and English subtitles together on Prime
Video. Hovering over a word pauses the video and shows what it means. A
subtitle is only on screen for about two seconds, so without pausing there
isn't time to read a translation. The translation happens on the device using
Chrome's Translator API, so there is no backend and no account.

`TypeScript` `Chrome Extension APIs`

### [vashabid](https://github.com/rickyfrancis/vashabid)

A Next.js 16 site built on Payload CMS 3 and PostgreSQL. It comes with a dev
container, so the database and tooling start the same way on any machine.

`Next.js` `Payload CMS` `PostgreSQL` `Docker`

### [issue-tracker](https://github.com/rickyfrancis/issue-tracker)

An issue tracker with login, assignment, filtering and dashboard charts.
[Live demo](https://issue-tracker-one-snowy.vercel.app)

`Next.js` `TypeScript` `Prisma` `NextAuth` `Radix UI`
